# Real Lanes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build per-direction lane counts that vary along roads, an Add-lane tool with tapers, and
traffic that chooses and changes lanes and passes junctions several cars at a time.

**Architecture:** A pure module, `src/roads/lanes.ts`, owns the lane geometry, the tapers, lane
continuity and turn assignment. The simulation, the renderer and the raster all read it. Each segment
carries `addR`/`addL` (the save format stays backward compatible). The worker switches to per-lane
queues and conflict-based junction admission.

**Tech Stack:** TypeScript, Three.js, Node `.mjs` tests with the resolve hook, and the in-process
worker harness (`tests/lane-traffic.mjs`).

**Spec:** `docs/superpowers/specs/2026-09-25-lanes-design.md`

## Global Constraints

- Default roads (addR = addL = 0) must render, rasterise and save exactly as before, and their lane
  centres must equal today's constants.
- `DEFAULT_LANES = [1, 2, 1, 3, 3, 1, 2]`, `LANE_WIDTH = [0.36, 0.43, 0.24, 0.44, 0.44, 0.6, 0.5]`,
  `TAPER = 1.6`, `MAXL = 6`. Limits: 4 lanes per direction on two-way roads, 6 on one-way roads,
  minimum 1.
- Lane 0 is the kerb lane (rightmost in the direction of travel). Positive offset is to the right of travel.
- Baseline throughput (`tests/lane-traffic.mjs`, 150 s): street 235, avenue 286. The avenue must
  reach ≥ 1.5 × 286 after Task 4.
- Every existing suite stays green after every task.

**Interfaces (produces):**
```ts
export const DEFAULT_LANES: number[]; export const LANE_WIDTH: number[]; export const TAPER = 1.6; export const MAXL = 6;
export const oneWay = (s: RSeg) => boolean                   // s.oneway || isOneWayKind(s.kind)
export function lanesFor(s: RSeg, fwd: boolean): number      // 0 for the back direction of a one-way road
export function sideHalf(s: RSeg, side: 1 | -1): number       // edge distance, right (+1) or left (-1), no taper
export function roadHalf(s: RSeg): number                     // max of both sides
export function laneCentre(s: RSeg, fwd: boolean, i: number): number  // offset right of travel, lane 0 = kerb
export function canAddLanes(s: RSeg, net: Network): boolean
export function laneLimits(s: RSeg): { minR: number; maxR: number; minL: number; maxL: number } // allowed addR/addL
export type Tapers = Map<number, [number, number, number, number]> // seg id -> target edge at [aRight, aLeft, bRight, bLeft], NaN = none
export function laneTapers(net: Network): Tapers
export function edgeAt(s: RSeg, side: 1 | -1, dist: number, tapers: Tapers): number
export function matchLanes(net: Network, fromSeg: RSeg, fromFwd: boolean, toSeg: RSeg, toFwd: boolean): number[] // per from-lane: to-lane or -1 (ends)
export interface Exit { seg: number; fwd: boolean; angle: number; lanes: number }
export interface Approach { exits: Exit[]; serve: number[][]; targets(lane: number, exit: number): number[] }
export function approachLanes(net: Network, node: number, seg: RSeg, fwd: boolean): Approach
```
In `Network`: `addLaneRange(id, s0, s1, side: 1 | -1, delta: 1 | -1): number[] | null`.

- [ ] Write tests covering the spec's list:

### Task 2: Rendering and raster read lane widths

`src/render/{crossings,pedestrians,streetlights,streetFurniture,parkedCars,bikeLanes,cyclists,streetDetail,transport,structures}.ts`,
`src/roads/network.ts` (`onRoad`, `vergeSpot` callers), `src/input.ts` previews,

### Task 3: Worker per-lane queues, lane choice and lane changes

**Files:** `src/sim/worker.ts`

- Queue key `(seg·2 + dir)·MAXL + lane`.
- New car fields `lane`, `nextLane`, `prevLane`, `chFrom`, `chP`, `chT`, `lcCool`, `box`, `boxLi`.
- `laneOffset` becomes lane-centre-based. `carPose` takes an explicit lateral offset.
- The needed lanes come from the cached `approachLanes`. Mandatory and overtaking changes with gap checks.
- Ramp drift is replaced. Trolleys stay in lane 0.
- The remap check includes lanes. The probe reports the real lane.
