# Per-movement Signals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Signal plans made of phases × arm-to-arm movements (green, yield or red), with a smart
default, optional adaptive timing, a junction editor with a 3D movement overlay, and lamps and traffic
that follow the plan.

**Architecture:** A pure module, `src/roads/signals.ts`, holds the plan model, the default plan, the
timeline and key renaming. The plan lives on `RNode.signal` and travels in `PlainNet.signals` and in
the save's JSON block. The worker runs a phase clock per light node and sends the clocks in each
frame. The renderer colours the lamps from those clocks. A DOM panel and a MeshBuilder overlay edit
the plan through ordinary network commits.

**Tech Stack:** TypeScript, Three.js, and Node `.mjs` tests with the in-process worker harness.

**Spec:** `docs/superpowers/specs/2026-09-25-signals-design.md`

## Global Constraints

- The movement key format is `${inSeg}${f|b}>${outSeg}${f|b}`, using segment ids in `Network`/`PlainNet`
  and segment indices only inside saves. States: 1 is green, 2 is yield, and a missing key is red.
- `AMBER = 1` s. A green is between 3 and 60 s, and 8 s by default. Adaptive greens run from a
  minimum of 3 s to at most 2× the set green.
- Every edit goes through `node.signal = plan; net.version++; game.flush()`, so it is undoable.
- Every existing suite stays green after every task.

### Task 1: `src/roads/signals.ts`, and plans on nodes, edits and saves

**Files:** Create `src/roads/signals.ts` and `tests/signals.mjs`. Modify `src/roads/network.ts`
(`RNode.signal`, `PlainNet.signals`, `toPlain`/`fromPlain`, `splitSeg`, `reverseSeg`, and `removeSeg`
clearing the plan), `src/save.ts` and `tests/all.mjs`.

**Produces:**
```ts
export const AMBER = 1;
export type MoveState = 1 | 2;
export interface SignalPlan { phases: { green: number; moves: Record<string, MoveState> }[]; adaptive?: boolean }
export const moveKey = (inSeg: number, inFwd: boolean, outSeg: number, outFwd: boolean): string
export interface Movement { key: string; inSeg: number; inFwd: boolean; outSeg: number; outFwd: boolean; angle: number }
export function movements(net: Network, node: number): Movement[]
export function defaultPlan(net: Network, node: number): SignalPlan
export function planFits(net: Network, node: number, plan: SignalPlan): boolean
export function planFor(net: Network, node: number): SignalPlan
export function stateIn(plan: SignalPlan, phase: number, t: number, len: number, key: string): 'green' | 'yield' | 'amber' | 'red'
export function cycleOf(plan: SignalPlan): number
export function fixedClock(plan: SignalPlan, time: number): { phase: number; t: number; len: number }
export function renameSeg(plan: SignalPlan, oldId: number, newId: number): void
export function flipSeg(plan: SignalPlan, segId: number): void
export function remapPlan(plan: SignalPlan, map: (segId: number) => number | undefined): SignalPlan | null
```
